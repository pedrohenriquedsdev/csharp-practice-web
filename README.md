## 🧭 Sobre este repositório

> **Aqui a prática vai para a web — APIs, interfaces, pipelines e tudo mais.**

Este repositório é dedicado à prática deliberada com **desenvolvimento web usando C# e .NET**. O foco é explorar o ecossistema completo: desde a criação de APIs RESTful até interfaces com Blazor, passando por autenticação, middlewares, Entity Framework e padrões de arquitetura aplicados em contexto web.

Cada exercício resolve algo real. Cada projeto tem estrutura intencional.

|---|---|---|

---

## 🏗️ Tecnologias & Abordagem

As práticas deste repositório cobrem um espectro amplo do desenvolvimento web .NET:

| Tecnologia | Foco |
|---|---|
| 🔌 **ASP.NET Core** | Pipeline HTTP, Middleware, Configuração |
| 🎮 **MVC** | Controllers, Views, Model Binding, Filters |
| ⚡ **Minimal APIs** | Endpoints enxutos, roteamento, versionamento |
| 📄 **Razor Pages** | Modelo page-centric para UIs simples e rápidas |
| 🔥 **Blazor** | Componentes interativos com C# no lugar de JS |
| 🗄️ **Entity Framework Core** | ORM, Migrations, relacionamentos, performance |
| 🔐 **Auth & Identity** | JWT, Cookies, ASP.NET Identity |
| 🧪 **Testes de Integração** | WebApplicationFactory, TestContainers |

> A cada exercício, a arquitetura é escolhida conforme o contexto — podendo ser **MVC, N-Tier, Modular, Clean Architecture** ou outra que se encaixe melhor no problema.
